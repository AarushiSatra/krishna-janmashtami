# Krishna — An Eternal Little Story

React + Vite Janmashtami experience.

## Image
Put the supplied Radha–Krishna swing artwork in:
`public/radha-krishna-swing.png`

The complete artwork is animated as the jhula swings gently left and right.

## Run
npm install
npm run dev

## Build
npm run build

Dahi Handi uses DeviceMotionEvent on phones. Tap Enable phone shake, allow motion, then shake the phone.
